# Samples

There are some samples we've created to help you integrate the Batch Barcode Scanner turn-in app into your workflow. You can find the source code on GitHub: <https://github.com/Dynamsoft/batch-barcode-scanner-samples/>

## Android Samples

Share-Receiver: This sample demonstrates how to create an Android app to receive scan results via sharing.

## Web Samples

Web Viewer: This sample demonstrates how to view scan results uploaded to a cloud platform like OneDrive. [Online demo](https://demo.dynamsoft.com/demo-bbs-web-viewer/).
