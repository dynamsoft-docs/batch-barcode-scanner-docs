# Android Release Notes

## 3.1.0 (09/22/2026)

**New Features:**

* Added history search.
* Added barcode result editing.
* Added output customization via JavaScript.

**Other Changes:**

* Renamed Wanted Barcode to Watchlist.
* Allowed the default OneDrive upload folder to be specified other than `BBS`.
* Allowed the default format to be unknown when entering barcodes manually.
* Improved UI text.



## 3.0.1 (06/16/2026)

* Improved UI to make usage easier to understand.
* Added an "Encode Video Decoding" setting.

## 3.0.0 (05/20/2026)

Initial Android version.
